SUD Gold Plus PWA V30.29

Contents:
- index.html: current Gold Plus V30.29 app
- manifest.webmanifest: app identity ("S") and Home Screen icons
- sw.js: offline cache/service worker
- icons/: iPhone/PWA icons
- vercel.json: static hosting configuration

After deployment to an HTTPS URL:
1. Open the URL on iPhone in Safari or Edge.
2. Share -> Add to Home Screen.
3. Keep "Open as Web App" enabled.
4. Name: S
5. Add.

Once installed, the S icon launches Gold Plus as a standalone Home Screen web app.
